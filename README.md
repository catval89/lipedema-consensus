# Lipedema Consensus Statements

A plain-language web page presenting the **59 Delphi consensus statements** on the definition and
management of lipedema, from the **Lipedema World Alliance** (2023 Lipedema World Congress, Potsdam),
each paired with a short commentary.

Built and maintained by **Lipedema Surgical Solutions** ([lipedema.net](https://lipedema.net)).

## 💬 How to suggest an edit

You're welcome to suggest corrections or improvements. **You'll need a free GitHub account.**

**Easiest — comment on a specific line or wording:**
1. Open an **[Issue](../../issues/new)** (the "Issues" tab above → "New issue").
2. Describe the change — quote the statement number or the text you mean. Done!

**Propose the exact wording yourself (a "pull request"):**
1. Open `index.html` here on GitHub and click the **✏️ pencil** ("Edit this file").
2. Make your change in the text.
3. Click **"Commit changes…"**, choose **"Create a new branch and start a pull request"**, and submit.
4. We'll review it and merge it in.

No edit is too small — typos, wording, or suggestions all help. Thank you! 💜
